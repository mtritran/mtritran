# 🌹 Generative ASCII Rose Bouquet Guide (mtritran)

README này được thiết kế theo tác phẩm nghệ thuật code **Generative ASCII Rose Bouquet**:
- **Hiệu ứng bó hoa hồng ASCII nở sống động**: Stems mọc lên, lá đâm chồi, 19 bông hồng nở rộ tỏa ánh sáng lấp lánh cùng dải ruy băng vàng và giấy gói bạc dưới bầu trời sao lung linh.
- **Tương tác trực tiếp trên máy**: File code [rose_bouquet.py](file:///d:/Projects/mtritran/rose_bouquet.py) chạy mượt mà 30 FPS bằng Python (`numpy` + `pygame-ce`).

---

## 💻 Cách chạy animation trực tiếp trên máy tính:

Mở Terminal / PowerShell tại thư mục `D:\Projects\mtritran`:

```bash
# 1. Cài đặt thư viện (nếu chưa cài):
pip install -r requirements.txt

# 2. Khởi chạy animation:
python rose_bouquet.py
```

**Các phím điều khiển khi đang chạy:**
- `Space`: Tạm dừng / Tiếp tục
- `R`: Khởi động lại quá trình hoa nở từ đầu
- `S`: Chụp ảnh màn hình lưu lại
- `Esc`: Thoát
